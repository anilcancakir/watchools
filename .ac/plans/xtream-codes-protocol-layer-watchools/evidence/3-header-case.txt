Web adapter: does NOT forward the flag
---------------------------------------
Checked /Users/anilcan/.pub-cache/hosted/pub.dev/dio-5.9.2/lib/src/adapters/browser_adapter.dart
and dio_web_adapter-2.2.2/lib/src/adapter_impl.dart:66,68. The web adapter writes headers via
`xhr.setRequestHeader(key, value)`, a browser API with no case-preservation hook of any kind.
This is a platform limitation of XMLHttpRequest, not a magic gap, and the fix in this PR does not
and cannot reach it. Scope observation only, per the briefing's instruction not to widen the PR.

The fix
-------
lib/src/network/drivers/dio_network_driver.dart: added `preserveHeaderCase: true` to the
driver's BaseOptions constructor.
