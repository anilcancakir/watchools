Both 200. Same body shape (Status / Answer[] / type / data / TTL); Google writes
the names fully qualified, which is not a field the parser reads, so one parser covers both.
A CNAME chain returns type 5 records whose "data" is a hostname, on both endpoints,
which is why records are filtered to type 1.
